2. Adaptive weight learning LinUCB contextual bandit

Four discrete scoring-weight profiles. balanced_pp1_baseline reproduces PP1's original fixed-weight formula as the experimental control; the other three are candidate arms the bandit explores. Bar length is ‖θ‖ (learned weight vector norm) per arm — this updates live over WebSocket the instant any feedback is recorded, from this page or the main app.

A fresh bandit starts at 0 obs on every backend restart (state is in-memory, by design — see app/api/dependencies.py) — the buttons above fire real synthetic requests through POST /simulate/batch, a genuine endpoint that runs real bandit updates against a known preference structure (emergency contexts prefer eta_heavy, normal contexts prefer rating_heavy), so you can watch real convergence happen live instead of clicking "select provider" dozens of times.

3. What's actually novel here

      
Static badges for panel reference — the live sections above are the proof these aren't just claims.

      

        
Online-learned ranking
LinUCB (Li et al. 2010) over discrete weight profiles, context = urgency × time-slot, reward from real user selection rank.

        
Provider reliability
Beta-Bernoulli posterior updated per completed job, feeds directly into the ranking score as a learned feature.

        
Hand-implemented routing
Priority-queue Dijkstra + A* (haversine heuristic) over a real OSM road graph, time-dependent traffic multipliers. Verified against networkx on 50 random pairs.

        
Hybrid retrieval
Dense vector similarity (Chroma) + BM25 keyword search, fused via Reciprocal Rank Fusion, not either alone.

        
Live availability
Background Markov-chain simulator mutates provider state independently of requests — never a static field.

        
Fail-closed context inference
Hybrid rules + LLM (TOON-serialized input, Pydantic-validated JSON output). Any LLM failure falls back to normal urgency — the pipeline never crashes on bad model output.

        
Deterministic scoring
The LLM only classifies context. Final ranking is always a deterministic weighted sum of agent-computed features — never model-generated.

        
Preserved baseline
PP1's exact static-weight formula still runs, as balanced_pp1_baseline — the before/after comparison is real, not reconstructed.
